# Code of conduct

## Our pledge

We want participating in this project to be free of harassment for everyone,
regardless of age, body size, visible or invisible disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behaviour

- Assume competence and good faith; criticise code, not people.
- Give and accept specific technical feedback. "This breaks X because Y" beats
  "this is bad".
- Respect that this project has opinions: it is a ledger, not a chat log. Argue
  with the reasons, not just the outcome.

## Unacceptable behaviour

Harassment, insults, sexualised language or imagery, doxxing, sustained
disruption of discussion, and publishing others' private information without
permission.

## Enforcement

Report to the maintainer through the repository's private security advisory
channel or a direct message. Reports are handled confidentially. Consequences
range from a warning to a permanent ban, at the maintainer's discretion.

This code applies in issues, pull requests, discussions, and any space where
someone is representing the project.
